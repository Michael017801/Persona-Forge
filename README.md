# Persona Forge

> 一套人格，十五个 AI 编程助手通用。
>
> One persona for 15 AI coding assistants.

---

## 这是什么 / What is this

**中文**

Persona Forge 把一份统一的人格写进 AI 编程助手的配置，让助手：

- 不再反复拒绝、说教
- 不再输出"作为 AI 我无法…"
- 按你设定的风格工作
- 直接给方案、直接改代码

全程本地，随时可还原，原程序不动。

**English**

Persona Forge writes one unified persona into your AI coding assistant's config, so the assistant:

- Stops refusing and lecturing
- Stops saying "as an AI I cannot…"
- Works in the style you define
- Gives answers and edits code directly

Fully local, fully reversible, original binaries untouched.

## 用法 / Usage

双击 `PersonaForge.exe`，勾选目标，点应用。

Double-click `PersonaForge.exe`, select targets, click Apply.
